## 视频排列拼接工具 v1.1.0

### BGM 预览与音量优化
- 新增 BGM 预览窗口：试听前 8 秒 + 音量滑块调节 (0.3 ~ 2.0)
- 默认 BGM 音量 0.80（原始混音已平衡）
- 音量分析显示（原视频/BGM 响度 dB）
- 关闭所有淡入淡出效果，纯物理叠加（amerge+pan）
- 修复关闭预览窗口导致 GUI 卡死的问题

### 界面优化
- 素材/输出目录旁新增"打开"按钮（主界面 + 设置弹窗）

### 修复
- 隐藏 ffmpeg 控制台弹窗（打包后不再闪黑窗口）

### 代码重构
- 拆分为多文件结构（core/ + gui/ + main.py）

### v1.0.0 基础功能
- 自动分组（字母+数字 / 关键词分组）
- 三种排列模式（有序/无序/部分固定）
- BGM 背景音乐（自动循环+均匀轮换+音量控制）
- 组别选择（勾选参与排列的组）
- Excel 排列表格（状态标记+颜色高亮+自动筛选）
- 断点续跑（中断后自动继续）
- 自动兼容不同分辨率/帧率
- 安装包自带 Python + ffmpeg，双击即用
