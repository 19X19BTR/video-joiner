# 🎬 Video Joiner - 视频排列拼接工具

自动扫描、分组、排列组合、拼接视频。支持 BGM 背景音乐、部分固定模式、关键词分组。打包成安装包，双击即用，无需 Python 环境。

## ✨ 功能特性

- **自动分组**：按首字母分组（`A1.mp4`、`B1.mp4`）或按关键词分组（`A=开头,B=痛点`）
- **三种排列模式**：有序（固定顺序）、无序（随机组序）、部分固定（指定组固定位置）
- **组别选择**：勾选参与排列的组别，灵活组合
- **BGM 背景音乐**：自动循环匹配视频长度、音量控制、尾端淡出、均匀轮换分布
- **断点续跑**：中断后重新运行，自动从上次断点继续
- **自动兼容**：不同分辨率/帧率自动统一，缺少音频的视频自动补静音
- **Excel 排列表格**：自动生成，带状态标记、自动筛选、颜色高亮
- **安装包发布**：PyInstaller + Inno Setup，用户无需装任何依赖

## 📦 安装

> 安装包路径：`dist/视频排列拼接工具_v1.0_安装包.exe`

## 🎯 使用方法

### 1. 准备素材

将视频放在同一个文件夹内，支持两种命名方式：

**方式 A：字母+数字命名**
```
input/20260601/
├── A1.mp4    ← A组第1个
├── A2.mp4    ← A组第2个
├── B1.mp4    ← B组第1个
├── B2.mp4    ← B组第2个
├── C1.mp4    ← C组第1个
└── D1.mp4    ← D组第1个
```

**方式 B：语义命名 + 关键词分组**
```
input/20260601/
├── 开头_产品介绍.mp4
├── 开头_品牌故事.mp4
├── 痛点_干燥脱皮.mp4
├── 痛点_暗沉发黄.mp4
├── 结尾_优惠活动.mp4
└── 效果_使用前后.mp4
```

在「组规则」输入框填写：`A=开头,B=痛点,C=结尾,D=效果`，文件名包含关键词即归入对应组。

### 2. 打开工具

```bash
python video_joiner_gui.py
```

### 3. 选择素材目录

点击「浏览」选择素材文件夹，工具会自动扫描并显示分组预览。

### 4. 设置参数

| 参数 | 说明 |
|------|------|
| **排列模式** | 有序（A→B→C→D）、无序（随机组序）、部分固定（指定组固定位置） |
| **拼接数量** | 本次要拼接的视频条数（表格会全量生成） |
| **输出分辨率** | 默认自动以第一个视频为准 |
| **BGM** | 勾选后从 BGM 目录自动轮换配乐 |

### 5. 开始拼接

- **「仅生成表格」**：生成 Excel 排列方案，不拼接视频
- **「开始拼接」**：生成表格 + 拼接视频（有表格则断点续跑）

### 6. BGM 设置

将背景音乐文件（mp3/wav/flac 等）放入 BGM 目录，工具会自动扫描。

- BGM 自动循环覆盖，匹配视频长度
- 尾端最后 2 秒自动淡出
- 池式轮换，确保每首 BGM 均匀分布
- 可在选择器中勾选/取消特定 BGM

## 📊 Excel 表格说明

| 列 | 说明 |
|----|------|
| 序号 | 排列编号 |
| A部分 / B部分 / ... | 该排列选取的各组视频 |
| 排列标识 | 如 `A1B2C3D1` |
| 拼接顺序 | 如 `A1 → B2 → C3 → D1` |
| 拼接状态 | ⏳待拼接 / ✅已完成 / ❌失败 |
| 输出文件 | 输出文件名 |

- 已完成的行自动标绿，失败标红
- 带自动筛选，可按状态快速过滤
- 支持断点续跑：中断后重新运行，自动读取未完成的排列继续拼接

## ⚙️ 排列模式详解

### 有序模式
固定 A→B→C→D 顺序，每组各取一个视频做笛卡尔积。

### 无序模式
每条排列的组序随机（如 B→D→A→C），每组视频也随机挑选。跨运行可复现（固定种子）。

### 部分固定模式
指定某些组保持原位，其余组随机排列。

示例：固定 A 和 C
```
A 永远第1位，C 永远第3位
B 和 D 在第2、4位随机
→ A1 B2 C1 D1
→ A1 D3 C1 B2
→ A2 B1 C2 D3
```

## 🔧 技术细节

- **GUI**：tkinter（Python 自带，无需额外依赖）
- **视频处理**：ffmpeg filter_complex（自动缩放、加黑边、统一分辨率/帧率）
- **BGM 混音**：ffmpeg amix（循环覆盖 + 裁切 + 淡出 + 音量控制）
- **Excel**：openpyxl（带样式、颜色、筛选）
- **打包**：PyInstaller（文件夹模式）+ Inno Setup（安装包）
- **配置持久化**：config.json 保存用户设置

## 📋 注意事项

1. 视频命名必须能被正确分组（字母+数字 或 关键词匹配）
2. 拼接大量视频时注意磁盘空间
3. 超过 500 种排列时会弹出确认提示
4. 部分固定模式下，固定组数不能等于或超过总组数
