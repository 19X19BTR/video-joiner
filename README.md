# 🎬 Video Joiner - 视频排列拼接工具

自动扫描、排列、拼接视频组。支持 A-Z 任意组数，一次性生成所有排列组合。

## 依赖

```bash
pip install openpyxl
# 系统需安装 ffmpeg（已在 PATH 中）
```

## 文件命名规则

所有视频放在同一个文件夹内，按 `{组别}{序号}.mp4` 命名：

```
input/20260601/
├── A1.mp4    ← A组第1个
├── A2.mp4    ← A组第2个
├── A3.mp4    ← A组第3个
├── B1.mp4    ← B组第1个
├── B2.mp4    ← B组第2个
├── C1.mp4    ← C组第1个
├── D1.mp4    ← D组第1个
```

- 组别：A-Z 大写字母（自动识别，几组都行）
- 序号：数字（1, 2, 3...）
- 代码会自动扫描首字母分组，按数字排序

## 使用方法

### GUI 版（推荐）

```bash
python video_joiner_gui.py
```

1. 点「浏览」选择素材目录
2. 选择排列模式（有序/无序）
3. 点「开始拼接」或「仅生成表格」

### 命令行版

```bash
# 有序排列
python video_joiner.py -i ./input/20260601 -m ordered

# 无序排列
python video_joiner.py -i ./input/20260601 -m unordered

# 指定输出目录
python video_joiner.py -i ./input/20260601 -m ordered -o ./my_output

# 仅生成表格
python video_joiner.py -i ./input/20260601 -m ordered --skip-encode
```

## 输出结构

```
output/20260601/
├── 20260601有序.xlsx         ← 有序排列表格
├── 20260601无序.xlsx         ← 无序排列表格
├── 20260601_A1B1C1D1.mp4    ← 拼接好的视频
├── 20260601_A2B1C1D1.mp4
└── ...
```

## 核心逻辑

### 「仅生成表格」
- 检查是否有表格 → 有则弹窗确认覆盖
- 一次性生成所有排列组合写入 Excel

### 「开始拼接」
- **没有表格** → 自动生成全部排列 → 开始拼接
- **有表格** → 读取表格，只拼接未完成的（断点续跑）
- 所有视频都已完成 → 提示"全部完成"

### 视频命名
```
20260601_A1B2C3D1.mp4
│       └── 各组视频名拼接
└── 日期文件夹名
```

## Excel 表格列说明

| 列 | 说明 |
|----|------|
| 序号 | 排列编号 |
| A部分 / B部分 / ... | 该排列选取的各组视频 |
| 排列标识 | 如 `A1B2C3D1` |
| 拼接顺序 | 如 `A1 → B2 → C3 → D1` |
| 拼接状态 | ⏳待拼接 / ✅已完成 / ❌失败 |
| 输出文件 | 输出文件名 |

- 表格带自动筛选，可按状态筛选
- 已完成的行自动标绿，失败标红
- 支持断点续跑：中断后重新运行，自动从断点继续

## 自动兼容

- 不同分辨率 → 自动缩放+黑边填充至目标分辨率
- 帧率 → 以第一个视频的帧率为准自动统一
- 缺少音频的视频 → 自动补静音轨道
- 全部无音频 → 输出纯视频流

## 注意事项

1. 视频命名必须以字母开头 + 数字，如 `A1.mp4`、`AB2.mp4`
2. 拼接大量视频时注意磁盘空间
3. 可用 `--skip-encode` 先预览排列方案再决定是否拼接
4. 超过 500 种排列时会弹出确认提示
